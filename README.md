# CSC13003 HW05 Performance Testing

Bài cá nhân của MSSV 23120262. Repo hiện ở bước chuẩn bị. Công cụ đề xuất là Apache JMeter để nộp trực tiếp test plan JMX, log JTL và báo cáo HTML theo đề. Phạm vi và thông số tải sẽ được chốt trước khi đo.

## Bắt đầu

1. Mở [checklist](TASKS.md) và đối chiếu lịch nộp trên Moodle.
2. Dùng [hướng dẫn setup](docs/test-workflow.md) để chuẩn bị Java, JMeter, bản EShop riêng và dữ liệu thử.
3. Dùng [ghi chú khảo sát](docs/references.md) khi xác minh API, chốt workflow và thiết kế kế hoạch đo.
