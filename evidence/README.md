# Bằng chứng

| Mục | Nội dung cần thu |
| --- | --- |
| Load, Stress, Spike | Mỗi lượt chính thức có ảnh JMeter và tài nguyên backend cùng khung, ghép được với run ID |
| Endurance | Thời lượng, mức tải, ảnh hoặc số liệu CPU và RAM theo thời gian |
| Hardware | Ảnh dxdiag hoặc tương đương, hostname dùng ở các HW trước, bảng CPU, RAM, hệ điều hành và phiên bản công cụ |
| GitHub Issues | Ảnh trang issue và liên kết tới hồ sơ lỗi nếu có |
| Demo | YouTube Unlisted, tổng ít nhất 6 phút, giọng tiếng Việt của sinh viên và JMeter cùng resource monitor trong khung |
| Agent Skill | Mốc thời gian hoặc video riêng minh họa trọn một nhóm endpoint |

Ghi người chạy và thời điểm theo bằng chứng thực tế.
